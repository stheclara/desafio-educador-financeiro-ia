>>Educador Financeiro Inteligente

Aplicação web de planejamento financeiro pessoal desenvolvida com React, TypeScript e Inteligência Artificial Generativa.

O projeto está sendo construído como parte de um desafio prático da DIO, utilizando o projeto Planej.ai como base técnica e referência.

A proposta é criar uma versão própria de um Educador Financeiro Inteligente, capaz de receber informações de uma simulação financeira e gerar análises, recomendações e próximos passos personalizados.

O Educador Financeiro Inteligente tem como objetivo ajudar o usuário a compreender melhor sua situação financeira.

A aplicação deverá permitir o preenchimento de informações como renda, gastos e objetivos financeiros. A partir desses dados, o sistema organizará a simulação e utilizará Inteligência Artificial Generativa para apresentar insights de forma clara e personalizada.

>>O objetivo deste projeto é praticar a construção de uma aplicação Front-End moderna, integrando recursos de desenvolvimento web com Inteligência Artificial.

>>Funcionalidades previstas para o projeto:

formulário financeiro em etapas;
acompanhamento do progresso da simulação;
campos monetários;
armazenamento das simulações no navegador;
página de resultado;
recuperação da simulação por identificador;
tema claro e escuro;
integração com IA Generativa;
geração de insights financeiros;
tratamento de carregamento e erros.

Esta seção será atualizada conforme as funcionalidades forem realmente implementadas e testadas.

>>A aplicação utilizará IA Generativa para interpretar os dados financeiros informados pelo usuário.
A proposta é gerar respostas como:

diagnóstico da situação financeira;
identificação de pontos de atenção;
recomendações personalizadas;
sugestões de organização;
próximos passos mais claros.
A integração será realizada com a API do Google Gemini.
